Chapter 6: Web Design Basics

Introduction

Web design involves creating visually appealing and functional web pages. A fundamental part of web design includes structuring elements, styling them, and ensuring a cohesive layout. In this chapter, you will gain a foundational understanding of CSS (Cascading Style Sheets)—from basic syntax and selectors to the Box Model, typography, and responsive design.

Understanding HTML and CSS

HTML (HyperText Markup Language) is used to structure web pages, while CSS (Cascading Style Sheets) is used to style them. CSS allows for adding colors, spacing, and positioning elements to create an engaging user experience.

Basic CSS Syntax

CSS consists of selectors and declarations. Here's an example:

h1 {
  color: #1e3a8a; /* Property: color, Value: #1e3a8a */
  font-size: 24px; /* Property: font-size, Value: 24px */
}
  • Selector: h1
    • This targets all <h1> elements on the page.
  • Declarations:
    • color: #1e3a8a; — This changes the text color of <h1> elements to a high-contrast deep blue.
    • font-size: 24px; — This changes the font size of <h1> elements to 24 pixels.

Summary of CSS Rule Structure:

  • The selector identifies which HTML element to style.
  • The declaration defines what style to apply, with each declaration made up of a property and its value.

Three Ways to Add CSS to HTML

There are three ways to apply CSS to an HTML document: inline, internal, and external. Knowing when to use each keeps your projects organized and easy to maintain.

1. Inline CSS (style Attribute)

Inline CSS applies styles directly to a single HTML element using the style attribute. While useful for quick one-off tests, it mixes content with presentation and is avoided in larger projects.

<p style="color: #14532d; font-size: 18px;">This paragraph uses inline CSS.</p>

2. Internal CSS (<style> Tag)

To add CSS to a single HTML document, you can use the <style> tag within the <head> section of the document. Anything you write inside the <style> tag will be applied as CSS styles to the HTML content on that page.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>

    <style>
        /* CSS styles go here */
        h1 {
            color: #1e3a8a;
            font-size: 24px;
        }

        p {
            color: #14532d;
            font-size: 16px;
        }
    </style>
</head>
<body>
    <h1>Welcome to My Page</h1>
    <p>This is a paragraph of text.</p>
</body>
</html>
  1. <style> tag:
    • It is placed inside the <head> section of the HTML document.
    • CSS code inside the <style> tag applies to that entire HTML document.
  2. When to use internal CSS:
    • It works well for single-page experiments or quick prototypes before moving styles into an external stylesheet.

3. External CSS (<link> Tag)

External CSS involves linking an HTML document to a separate .css file. This method is the most efficient for multi-page projects, as it allows for a clean separation of content and design and lets you update styles across an entire site by editing a single file.

To use external CSS, create a separate CSS file (such as style.css) and link it to your HTML document using the <link> tag in the <head> section:

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
    <link rel="stylesheet" href="style.css">
</head>
  • Consistency: Linking all pages to a single CSS file ensures that changes to the design are applied universally across your website.
  • Efficiency: External CSS reduces redundancy and file size in HTML documents, as styles are defined once in a separate file rather than repeated within each page.

Targeting Elements: Selectors, Classes, and IDs

Styling every <p> or <div> identically is rarely enough for a real webpage. CSS provides specific selectors so you can target reusable groups of elements or a single unique element.

Comparison of Core CSS Selector Types
Selector Type CSS Syntax HTML Attribute When to Use
Element (Tag) p { ... } <p> Sets default styling for every instance of an HTML tag.
Class .card { ... } class="card" Applies reusable styles to multiple elements across a page.
ID #main-banner { ... } id="main-banner" Targets one unique element that appears only once per page. 
/* 1. Element selector: styles ALL paragraphs */
p {
    color: #111827;
}

/* 2. Class selector: reusable style for multiple elements */
.highlight-box {
    background-color: #f1f5f9;
    padding: 16px;
}

/* 3. ID selector: unique style for one specific element */
#site-title {
    color: #0f172a;
    font-size: 32px;
}

The Cascade and Specificity

The "C" in CSS stands for Cascading. When multiple rules target the same element, the browser resolves conflicts using specificity (how targeted a selector is) and source order:

  1. Inline styles (style="...") override internal and external rules.
  2. ID selectors (#id) override class and element selectors.
  3. Class selectors (.class) override element selectors.
  4. Element selectors (h1, p) have the lowest specificity; if two equal rules conflict, the rule written last wins.

The CSS Box Model

In CSS, every HTML element is rendered as a rectangular box. Understanding the Box Model is essential for controlling spacing, borders, and page layouts (including Flexbox in Chapter 7).

1. Content
The inner area where text, images, or child elements appear, controlled by width and height.
2. Padding
Transparent space inside the element, between the content and the border.
3. Border
A visible or invisible line wrapping around the padding and content.
4. Margin
Transparent space outside the border that pushes neighboring elements away.
.card {
    width: 300px;
    padding: 20px;              /* Inner breathing room */
    border: 2px solid #1e40af;  /* Visible frame */
    margin: 16px;               /* Outer space separating cards */
    box-sizing: border-box;     /* Keeps total width at 300px including padding & border */
}

Best Practice — Always Use box-sizing: border-box;: By default, CSS adds padding and borders on top of an element's declared width. Adding * { box-sizing: border-box; } at the top of your stylesheet (just like our course style.css does) ensures that a 300px box stays exactly 300px wide.

Core Typography and Color Properties

Readable typography and high-contrast color palettes make webpages clear, accessible, and easy to scan.

  • font-family: Specifies the typeface, usually listing fallback fonts (for example, Arial, Helvetica, sans-serif).
  • font-weight: Controls text thickness, such as normal (400) or bold (700).
  • line-height: Controls vertical spacing between lines of text; a value of 1.5 or 1.6 improves readability.
  • text-align: Aligns text horizontally (left, center, or right).
  • background-color: Sets the surface fill color behind an element's content and padding.
  • Hexadecimal (Hex) Colors: Six-digit codes like #111827 (near-black) or #f1f5f9 (soft slate) give exact control over color contrast.
body {
    font-family: Arial, Helvetica, sans-serif;
    line-height: 1.6;
    color: #111827;
    background-color: #ffffff;
}

.banner {
    background-color: #1e3a8a;
    color: #ffffff;
    text-align: center;
    padding: 24px;
}

Introduction to Responsive Design and Media Queries

Visitors view websites on everything from small smartphones to wide desktop monitors. Responsive web design ensures your layout adapts smoothly to any screen width.

First, always include the viewport <meta> tag in your HTML <head> so mobile browsers scale the page accurately. Second, use a CSS @media query to adjust styles when the viewport meets a specific width condition:

/* Default style for desktop screens */
.box {
    width: 50%;
    padding: 24px;
    background-color: #f1f5f9;
}

/* Adjusts automatically on screens 768px wide or smaller */
@media (max-width: 768px) {
    .box {
        width: 100%;
        padding: 16px;
    }
}

Introduction to CSS Zen Garden

CSS Zen Garden is an online resource that allows designers to submit their own CSS designs to transform a single HTML file. The purpose of this site is to highlight the capabilities of CSS in creating visually appealing web pages without altering the HTML structure. By visiting CSS Zen Garden (opens in new tab), you can explore a variety of designs, each demonstrating unique styles and layouts, all applied to the same HTML content.

How to Use CSS Zen Garden

  1. Visit the Site: Start by navigating to the CSS Zen Garden website. Here, you will find a default design along with a menu of other designs created by various designers.
  2. Explore Designs: On the homepage, you can browse through different designs by clicking on their titles or thumbnails. Each design applies a unique CSS file to the same HTML structure, allowing you to see how different styles can completely change the look and feel of a webpage.
  3. View the HTML: To understand the foundation of these designs, you can view the HTML file used. This file remains constant across all designs, emphasizing the role of CSS in altering the presentation.
  4. Examine the CSS: For each design, you can also view the CSS file. This is where all the styling magic happens. By examining these files, you can learn how different CSS properties and techniques are used to achieve various visual effects.
⚖️ ETHICAL SPOTLIGHT

Dark Patterns in Layout and Visual Hierarchy

As developers learn to master CSS, layout structures, and visual hierarchy, they gain immense power to shape user decisions. However, when design principles are intentionally weaponized to manipulate users into taking actions against their own best interests, web design degrades into deceptive coercion known as a "dark pattern."

The Ethical Quandary: Visual Coercion in Consent Banners

The Scenario: Consider a modern cookie consent banner: the "Accept All Cookies" option is styled as a large, vibrant, high-contrast primary button that instantly draws the eye. In stark contrast, the "Reject All" option is rendered as a tiny, low-contrast text link hidden at the bottom of the dialog or buried beneath multiple sub-menus.

The Question: Is using deceptive visual hierarchy and deliberate visual friction an acceptable optimization strategy to maximize data collection, or is it an unethical breach of user trust?

Philosophical Framework: Kantian Deontology & Rational Agency (Immanuel Kant)

Immanuel Kant argued in his Groundwork of the Metaphysics of Morals that rational human beings must always be treated as ends in themselves, never merely as a means to an end. Deceiving users through biased visual layouts manipulates their cognitive vulnerabilities, degrading their rational agency and reducing human beings to revenue metrics or data-harvesting assets.

Thought Experiment for Web Designers:

When you build a user interface, does your visual hierarchy empower visitors to make clear, autonomous decisions, or does it exploit visual friction to trick them into surrender? If a conversion goal requires deceiving the user to succeed, is that a triumph of visual design or a failure of moral integrity?

Conclusion

In this chapter, we’ve explored the fundamentals of web design, focusing on the essential roles of HTML and CSS. HTML is the backbone of web structure, allowing us to define the content of web pages, while CSS controls visual presentation through selectors, the Box Model, typography, color, and responsive media queries.

We’ve learned how to apply CSS inline, internally within a <style> tag, or by linking to external CSS files—with external CSS serving as the best choice for multi-page projects due to its consistency and maintainability.
