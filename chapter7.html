Chapter 7: CSS Techniques

Introduction

In Chapter 6, you learned how CSS selectors, the Box Model, typography, and media queries style individual elements. In this chapter, you will build on those fundamentals to arrange multi-column layouts and add accessible motion using Flexbox, CSS Grid, responsive layout patterns, and CSS transitions and animations.

Part 1: Flexbox for One-Dimensional Layout

Among modern layout tools, Flexbox (Flexible Box Layout) stands out as an efficient method for arranging items in a single row or a single column. Turning a parent element into a flex container gives you direct control over alignment, spacing, wrapping, and direction.

How Flexbox Works

  1. The Flex Container (display: flex;): Applying display: flex; to a parent element turns all of its direct children into flex items.
  2. Main Axis and Cross Axis: By default, flex items sit side by side along the horizontal main axis, while the vertical direction acts as the cross axis.
  3. justify-content: Aligns and distributes items along the main axis (for example, space-between or center).
  4. align-items: Aligns items along the cross axis (for example, center or stretch).
  5. gap and flex-wrap: gap adds consistent spacing between flex items, and flex-wrap: wrap; lets items wrap onto a new row instead of overflowing narrow screens.

Example: A Responsive Flexbox Card Row

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flexbox Layout</title>
    <style>
        * {
            box-sizing: border-box;
        }
        .flex-row {
            display: flex;                  /* Turn container into a flex container */
            justify-content: space-between; /* Distribute items across the main axis */
            align-items: center;            /* Align items along the cross axis */
            gap: 16px;                      /* Clean spacing between items */
            min-height: 220px;
            padding: 16px;
            background-color: #f1f5f9;
        }
        .flex-item {
            flex: 1;                        /* Share available row width equally */
            padding: 20px;
            background-color: #ffffff;
            color: #111827;
            border: 2px solid #1e40af;
            border-radius: 6px;
            text-align: center;
        }

        /* Stack items vertically on mobile viewports (768px and below) */
        @media (max-width: 768px) {
            .flex-row {
                flex-direction: column;
                align-items: stretch;
            }
        }
    </style>
</head>
<body>
    <div class="flex-row">
        <div class="flex-item">Item 1</div>
        <div class="flex-item">Item 2</div>
        <div class="flex-item">Item 3</div>
    </div>
</body>
</html>

Key Flexbox Properties Summary

  • display: flex; activates Flexbox on the parent container.
  • justify-content: space-between; distributes items evenly across the main axis.
  • align-items: center; centers items vertically along the cross axis.
  • gap: 16px; creates uniform space between flex items without extra margin rules.
  • flex-direction: column; switches the main axis from horizontal to vertical—ideal inside a @media (max-width: 768px) query for mobile devices.

Part 2: Introduction to CSS Grid Layout

While Flexbox excels at arranging items along one dimension (a row or a column), CSS Grid is built for two-dimensional layouts—controlling both columns and rows at the same time.

Choosing Between Flexbox and CSS Grid
Layout System Dimensions Best Used For
Flexbox (display: flex) One-dimensional (row or column) Navigation bars, button groups, centering content, and single-row card strips.
CSS Grid (display: grid) Two-dimensional (rows and columns) Full-page layouts, photo galleries, dashboards, and multi-row card grids.

Example: A Responsive Three-Column Grid

.photo-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr); /* 3 equal-width fractional columns */
    gap: 16px;
}

.grid-card {
    background-color: #f8fafc;
    color: #111827;
    border: 2px solid #1e3a8a;
    padding: 20px;
    border-radius: 6px;
}

/* Collapse to a single column on screens 768px wide or smaller */
@media (max-width: 768px) {
    .photo-grid {
        grid-template-columns: 1fr;
    }
}
  • display: grid; turns a parent element into a grid container.
  • grid-template-columns: repeat(3, 1fr); defines three columns that each take up one equal fraction (1fr) of the available space.
  • gap: 16px; sets consistent spacing between both rows and columns.

Part 3: CSS Transitions, Animations, and Accessible Motion

Subtle motion can provide helpful visual feedback when learners or visitors interact with buttons, links, and cards.

Transitions: Smooth Changes on Hover and Focus

CSS transitions smoothly animate property changes over a set duration—most commonly when a user hovers over or focuses on an interactive element.

.interactive-box {
    width: 220px;
    padding: 20px;
    background-color: #1e3a8a;
    color: #ffffff;
    font-weight: bold;
    text-align: center;
    border-radius: 6px;
    transition: background-color 0.3s ease, transform 0.3s ease;
}

.interactive-box:hover,
.interactive-box:focus-visible {
    background-color: #14532d;
    transform: scale(1.05);
}

Animations: Multi-Step Sequences with @keyframes

CSS animations use a @keyframes rule to define intermediate checkpoints from 0% (start) to 100% (end), allowing elements to animate automatically without requiring a hover trigger.

.animate-badge {
    display: inline-block;
    padding: 12px 20px;
    background-color: #14532d;
    color: #ffffff;
    font-weight: bold;
    border-radius: 6px;
    animation: slide-shift 3s ease-in-out infinite;
}

@keyframes slide-shift {
    0%   { transform: translateX(0); }
    50%  { transform: translateX(40px); }
    100% { transform: translateX(0); }
}

Accessibility Best Practice — Respecting prefers-reduced-motion: Continuous or large-scale motion can trigger dizziness and discomfort for people with vestibular sensitivities (a core principle of WCAG Level AAA). Always include a prefers-reduced-motion media query to turn off non-essential animations when a user enables "Reduce Motion" in their device settings:

@media (prefers-reduced-motion: reduce) {
    .animate-badge {
        animation: none;
    }
    .interactive-box {
        transition: none;
    }
}

Conclusion

In this chapter, you expanded your CSS toolkit from styling individual boxes to building adaptive page layouts. You learned how Flexbox aligns items along a single axis, how CSS Grid organizes two-dimensional columns and rows, and how @media breakpoints adapt both systems to smaller screens.

You also saw how CSS transitions and @keyframes animations add interactive polish—and how pairing them with @media (prefers-reduced-motion: reduce) ensures your designs remain comfortable and accessible for every visitor.
